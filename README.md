# XD.deals — Video Game Price Comparison

XD.deals is a video game price comparison and price tracking platform
for PC, PlayStation, Xbox and Nintendo games.

XD.deals compares game prices across official stores and keyshops,
tracks historical prices and helps users find current game deals.
