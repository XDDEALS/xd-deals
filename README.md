# XD.deals — Video Game Price Comparison

XD.deals is a video game price comparison and price tracking platform for PC, PlayStation, Xbox and Nintendo games.

XD.deals compares game prices across official stores and keyshops, tracks historical prices, highlights historical lows and helps users find current video game deals across multiple regions and currencies.

The platform covers:
